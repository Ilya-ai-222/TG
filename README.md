🤖Название бота: carAI.
Бот использует keras model для создания и обучения модели. Он весьма прост и может быть переделан. Получить собственную модель можно через инструмент teachable machine.         
Функционал заключается только в том, чтобы определить марку машины по фото.                                 
⚙️Краткое описание технических характеристик бота:
1. Написан c помощью библиотеки Telegram bot API и довольно прост в устройстве.
2. Требует установки библиотек:                                                   
pip install pyTelegramBotAPI                         
pip install tensorflow                     
pip install pillow                          
pip install numpy                      
3. Имеет небольшое количество команд, только "help" и "start". Реагирует на другие сообщения, картинки.
4. Все классы прописаны в labels.txt                               
В целом бот является скорее заготовкой, чем полноценным проектом.

🤖Bot name: carAI.
The bot uses a Keras model to create and train the model. It is quite simple and can be modified. You can get your own model using the teachable machine tool.
The functionality is limited to identifying the make of a car from a photo.
⚙️Brief description of the bot’s technical specifications:                                            
1. It was written using the Telegram bot API library and is quite simple in design.
2. Requires installing the following libraries:
pip install pyTelegramBotAPI
pip install tensorflow
pip install pillow
pip install numpy                          
1. It has a small number of commands, only "help" and "start". It responds to other messages and images.
4. All classes are defined in labels.txt
Overall, the bot is more of a draft than a full‑fledged project. You can get your own model using the teachable machine tool.
